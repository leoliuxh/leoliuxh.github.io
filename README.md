# Xiaohan Liu — Personal website

Live at https://leoliuxh.github.io/

A static, responsive portfolio hosted on GitHub Pages. No build step or JavaScript required.

## Editing

- `index.html`: content and links
- `style.css`: layout, colors, typography
- `assets/Xiaohan_Liu_resume.pdf`: downloadable resume (phone number omitted)

Push changes to `main` to update the site. Preview locally with `python3 -m http.server 8000`.
